# Portfólio Pessoal

Site portfólio desenvolvido como atividade acadêmica para apresentar minha trajetória, projetos e atividades.

## Objetivo

Servir como complemento ao currículo, reunindo atividades acadêmicas, projetos, eventos, sites desenvolvidos e formas de contato.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git e GitHub Pages

## Estrutura de pastas

```
portfolio/
├── index.html        # Estrutura e conteúdo das seções
├── README.md         # Documentação
├── css/
│   └── style.css     # Estilos e responsividade (mobile first)
├── js/
│   └── script.js     # Interações e validação
├── img/              # perfil.jpg e projeto1.jpg a projeto4.jpg

## Comandos Git

git init
git add .
git commit -m "Primeira versão do portfólio"
git branch -M main
git remote add origin URL_DO_REPOSITORIO
git push -u origin main
```

Antes do `git remote add`, crie um repositório vazio no GitHub e copie a URL dele (por exemplo, `https://github.com/seu-usuario/portfolio.git`).

## Publicação no GitHub Pages

1. No repositório, abra **Settings** e depois **Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Aguarde alguns minutos. O site ficará em `https://seu-usuario.github.io/portfolio/`.
5. Para atualizar, faça `git add .`, `git commit -m "Descrição da mudança"` e `git push`.
